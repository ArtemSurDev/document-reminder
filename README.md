# Сервис напоминаний о сроках документов

## Назначение

Приложение предназначено для учёта документов с ограниченным сроком действия
и своевременного оповещения пользователя о приближении или наступлении
крайнего срока. Сервис помогает не пропустить дату продления паспорта,
окончания договора, срока действия лицензии, страховки и других документов.

## Целевая аудитория

- Частные пользователи, которым важно отслеживать сроки личных документов
  (паспорт, водительские права, страховка, виза).
- Сотрудники организаций, ответственные за документооборот
  (договоры, лицензии, сертификаты).
- Фрилансеры и предприниматели, работающие с большим количеством
  контрактов и разрешительных документов.

## Предметная область

Предметная область — учёт документов и управление сроками их действия.
Каждый документ имеет тип, номер, дату выдачи, дату окончания и статус.
Пользователь может добавлять документы, устанавливать напоминания
и получать уведомления о приближении срока.

## Основные сущности

- **Пользователь** — владелец документов, получатель напоминаний.
- **Документ** — конкретный документ с реквизитами и сроком действия.
- **Категория** — тип документа (личный, рабочий, финансовый и т.д.).
- **Напоминание** — правило оповещения (за сколько дней предупредить).

## Основные функции

- **`days_until_expiry(expiry, current)`** — расчёт количества дней до окончания срока действия документа.
- **`get_status(days_left)`** — проверка статуса документа (действителен / истекает скоро / истекает сегодня / просрочен).
- **`format_notification(user, title, days_left)`** — формирование текста напоминания для пользователя.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL);
- реализация пользователей и аутентификации;
- разработка REST API;
- контейнеризация приложения (Docker);
- настройка CI/CD.
