# Сервис напоминаний о сроках документов

## Назначение

Приложение для учёта документов с ограниченным сроком действия
и оповещения пользователя о приближении или наступлении крайнего срока.
Помогает не пропустить дату продления паспорта, окончания договора,
срока действия лицензии, страховки и других документов.

## Целевая аудитория

- Частные пользователи, отслеживающие сроки личных документов.
- Сотрудники организаций, ответственные за документооборот.
- Фрилансеры и предприниматели с большим количеством контрактов.

## Предметная область

Учёт документов и управление сроками их действия.
Пользователь регистрирует документы, для каждого документа
устанавливается дата окончания срока и правило напоминания.
При приближении срока формируется уведомление.

## Основные сущности

- **Пользователь** — владелец документов, получатель уведомлений.
- **Документ** — запись с полями `id`, `title`, `number`, `expiry`, `owner_id`.
- **Срок** — дата окончания действия документа и правило напоминания.
- **Уведомление** — текстовое сообщение о приближении или наступлении срока.

## Основные функции

- **`add_document`** — добавление документа в список.
- **`find_documents`** — поиск документов по подстроке в названии.
- **`days_until_expiry`** — расчёт количества дней до окончания срока.
- **`get_status`** — определение статуса документа.
- **`format_notification`** — формирование текста уведомления.
- **`get_expiring_documents`** — отбор документов с ближайшими сроками.
- **`sort_documents_by_expiry`** — сортировка документов по дате.
- **`get_statistics`** — статистика по документам.
- **`add_user`** — добавление пользователя.
- **`find_user`** — поиск пользователя по имени.

## Структура проекта

- `main.py` — точка входа, меню и вывод;
- `documents.py` — функции обработки документов;
- `users.py` — функции работы с пользователями;
- `notifications.py` — функции работы с уведомлениями;
- `storage.py` — сохранение и загрузка JSON;
- `utils.py` — безопасный ввод;
- `data/documents.json` — данные о документах;
- `data/users.json` — данные о пользователях;
- `data/notifications.json` — данные об уведомлениях;
- `tests/` — автоматизированные тесты.
